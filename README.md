# Gym Tracker

Aplikacja PWA (działa offline). Wszystkie dane zapisują się lokalnie w telefonie.

## Publikacja na GitHub Pages
1. Utwórz repozytorium na GitHub i wgraj wszystkie pliki z tego folderu (z zachowaniem folderu `icons`).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save.
3. Po minucie strona będzie pod `https://TWOJ_LOGIN.github.io/NAZWA_REPO/`.

## Instalacja
- **Android (Chrome):** otwórz link → menu ⋮ → „Zainstaluj aplikację".
- **iPhone (Safari):** otwórz link → Udostępnij → „Dodaj do ekranu początkowego".
- Otwórz aplikację raz z internetem, żeby zapisała się w pamięci podręcznej — potem działa offline.
